# Screenshots

Drop PNGs here with these exact names - the root `README.md` references them.
Until a file exists, GitHub renders a broken-image placeholder in its slot.

| File | What to capture |
|---|---|
| `general.png` | Main window, General view, a bundle open (the hero image) |
| `inventory.png` | Inventory view: app list + detail pane, ideally with nested groups expanded |
| `settings-managed.png` | Settings with policy-managed fields showing padlocks and the *Managed by your organization* chip |
| `templates.png` | The Save Template dialog with its field picker |
| `scripts.png` | Scripts view with the Monaco editor |
| `run.png` | Run view mid-package, with background jobs visible |
| `detection.png` | Detection view with a rule configured |
| `history.png` | Git History view with commits listed |

Capture at 1440–1920 px wide on the dark theme for consistency; the README
displays the hero at 900 px and the tour grid at 440 px.

**Before publishing a screenshot, check it for organization data** - tenant and
site names, the title-bar bundle path, real app names, group names, and the
signed-in account chip. Use a scratch bundle and a demo tenant where possible.
